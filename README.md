# Rapat & Tindak Lanjut — YEH/UNEKA

Aplikasi web untuk pokok bahasan, rapat, hasil rapat (notulen), tindak lanjut, dan arahan.
Data tersimpan di Google Spreadsheet melalui Apps Script.

- Versi web: lihat `src/config.js` (APP_VERSION).
- Alamat server: `API_URL` di `src/config.js` (URL Web App Apps Script berakhiran /exec).
- Terbit otomatis ke GitHub Pages setiap ada perubahan di cabang `main`.
